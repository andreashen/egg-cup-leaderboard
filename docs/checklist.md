# 英超竞猜榜单项目验收清单

## 当前里程碑验收

- [ ] 当前里程碑能从 `premierleague.com` 页面背后的 JSON 数据入口获取原始数据。
- [ ] 当前里程碑能输出 `standings`、`metadata` 等规范化结果。
- [ ] 当前里程碑会同时保存原始抓取快照和规范化后的中间数据。
- [ ] 当前里程碑在请求失败、字段缺失或结构漂移时会失败并保留日志。
- [ ] 当前里程碑的最小闭环不要求赛程明细接口可用。
- [ ] 当前里程碑的完成标准不要求计分引擎、页面展示和 GitHub Actions 发布已经完成。

## 功能验收

- [ ] 能读取玩家竞猜 CSV，并正确解析前四、黑马和黑驴字段。
- [ ] 能将竞猜中的球队名称稳定映射到统一标准球队标识。
- [ ] 能从 `premierleague.com` 相关数据源获取当前赛季积分榜和轮次信息。
- [ ] 能保存原始抓取快照和规范化后的中间数据。
- [ ] 能读取 `data/seasons/2025-26.yml`、`data/team_aliases.csv` 和 `data/baselines/2024-25_table.csv` 并正常参与计算。
- [ ] 能根据规则正确计算前四、黑马、黑驴和总分。
- [ ] 能识别并处理无效竞猜（如上赛季前三猜黑马、升班马猜黑驴），确保此类竞猜不会错误加减分。
- [ ] 能输出玩家总积分榜和每位玩家的分项明细。

## 页面验收

- [ ] GitHub Pages 首页可正常访问。
- [ ] 页面标题下方显示数据更新时间和当前已更新轮次或比赛进度。
- [ ] 首页展示按总分降序排列的玩家总积分榜。
- [ ] 每位玩家可在首页内展开查看前四、黑马、黑驴的得分拆解。
- [ ] 页面展示当前英超积分榜快照。
- [ ] 页面数据来自生成的 JSON 文件，而不是手写静态内容。

## 自动化验收

- [ ] GitHub Actions 支持每 6 小时定时触发。
- [ ] GitHub Actions 支持手动触发。
- [ ] 定时任务可完成抓取、计分、生成页面和发布流程。
- [ ] 当抓取失败或解析失败时，流程会失败并保留日志，不发布异常结果。
- [ ] 当内容无变化时，流程不会产生无意义发布。

## 正确性验收

- [ ] 规则文档中的示例能够得到预期分数或与设计口径一致的计算结果。
- [ ] 真实竞猜示例可成功跑通端到端流程。
- [ ] 升班马、黑马失败扣分、黑驴失败扣分等边界场景均有验证。
- [ ] 球队别名、中文名、英文名和官网命名之间不存在歧义映射。

## 可维护性验收

- [ ] 数据源适配层、计分层和页面生成层职责分离。
- [ ] 下赛季切换时，主要通过更新赛季配置、球队基线和球队映射即可复用。
- [ ] 关键中间产物和日志可用于排查官网结构变化或计分异常。
- [ ] `.gitignore` 已覆盖本地调试产物、Python 缓存和生成目录，避免无关文件进入版本库。
- [ ] README、`docs/spec.md`、`docs/tasks.md` 和 `docs/checklist.md` 内容完整且相互一致。
